Sources: CPI = FRED CPIAUCNS (NSA, BLS basis) · Core PCE = FRED PCEPILFE · NFP = FRED PAYEMS month-over-month change (reflects revisions) · Real Yield = FRED DFII10 (H.15) · DXY = computed live from ECB reference rates (Frankfurter, no key) via the official ICE weights — typically within ±0.3 of ICE futures DXY · Consensus = manual log (US_RELEASES / US_UPCOMING); no automated consensus feed is used.
Fetch path: the local server (Open_Indian_Macro_Dashboard.cmd) fetches FRED server-side on every page open/reload, within each series' reuse window, and saves validated data to data/macro_snapshot.js. No public CORS proxies are used. DXY is an estimate from ECB reference rates with the ICE weights (50.14348112 × EURUSD^−0.576 × USDJPY^0.136 × GBPUSD^−0.119 × USDCAD^0.091 × USDSEK^0.042 × USDCHF^0.036), not the traded index. Consensus forecasts are manual (US_RELEASES / US_UPCOMING): the ForexFactory feed refuses automated clients and is not bypassed. Baseline values verified –; per the no-interpolation rule, deltas needing a daily series show n/a in BASELINE mode rather than estimated values.
Impact Score: 0–100 (50 = neutral), weighted on Real-Yield trend & level, DXY 30-day trend, latest CPI surprise and NFP surprise. Weights are in US_SCORE_WEIGHTS in the source. Known blind spot: the model does not capture safe-haven bids (e.g. war escalation can lift gold even with rising real yields).
Surprise Tracker: two bullet panels — filled bar = Actual print, grey tick = Forecast (consensus), gap = surprise; inflation (CPI/Core CPI/Core PCE, pp) on top, NFP (K jobs) below. Upcoming releases from US_UPCOMING (+ live FF) render as dashed hollow bars that auto-fill once US_RELEASES gains the dated actual. True time axis (type:'time' via date-fns adapter) so horizontal spacing = real calendar days; same-day prints are nudged ±days to de-collide. Sign convention: + = hawkish. Blind spot: a "0.0pp" surprise can still move markets via positioning or internals (core MoM, revisions) — revisions (e.g. NFP Apr 115K→179K) are a separate channel not shown as a bar.
Impact Tracker: maps the recent surprise sequence (last 3 inflation prints + last NFP + DXY trend) to Gold ETFs, Silver ETFs, Nifty Next 50 and Small Caps as headwind/tailwind. Rule-based and directional only — not advice; safe-haven bids and FII positioning can override. Small caps are flagged most DXY/liquidity-sensitive.
Monthly Trends: CPI + Core PCE + Real Yield share one % chart (gaps left null, no interpolation); NFP (K jobs) and DXY (index) kept separate as their scales don't mix. Tags use the same states as the cards (LATEST / CACHED / SNAPSHOT / STALE / BASELINE). YoY is matched by calendar month, so a month FRED lacks (e.g. Oct-2025 CPI, never published) yields no point rather than a 13-month change.
▸ Data Sources, Provenance & Methodology
RBI Repo Rate
Card: current Policy Repo Rate read from the RBI home page "Current Rates" block by the local server (validated: SDF < repo < MSF). The page does not state the decision's effective date, so none is shown.
Chart: quarter-end levels from verified MPC decisions, maintained manually in FALLBACK.repo. Quarters after the last verified decision are left blank, never estimated.
rbi.org.in · Current Rates
◆ Baseline
CPI Inflation (YoY)
Series: MoSPI CPI (General), All-India, Combined (rural+urban). Card = latest monthly YoY as published. Chart = mean of the quarter's 3 monthly YoY prints (complete quarters only).
Base break: Jan 2021–Dec 2025 from base 2012; Jan 2026 onward from base 2024 (MoSPI's published YoY). Growth rates are shown, not spliced index levels.
Cross-check: World Bank FP.CPI.TOTL.ZG annual (calendar year) vs the chart's calendar-year average. Never replaces the chart.
esankhyiki.mospi.gov.in · CPI
◆ Baseline
GDP Growth (YoY)
Series: MoSPI National Accounts, quarterly GDP at constant prices (real). YoY = level ÷ same quarter a year earlier − 1. Fiscal Q1 (Apr–Jun) is plotted as calendar Q2.
Base: 2022-23 series where both quarters exist (Apr–Jun 2023 onward); earlier quarters from the superseded 2011-12 series. Latest estimates as revised by MoSPI, not first prints.
Cross-check: World Bank NY.GDP.MKTP.KD.ZG (India fiscal year) vs the chart's Apr–Mar average. Never replaces the chart.
esankhyiki.mospi.gov.in · National Accounts
◆ Baseline
USD / INR
ECB euro reference rates (published ≈16:00 CET on TARGET business days) via Frankfurter, crossed to USD. A daily reference rate, not a live market quote. Chart = last reference rate on or before each quarter end.
Note: ECB reference ≠ FBIL/RBI rate — typically differs by a few paise; published ~16:00 CET working days.
api.frankfurter.dev · USD→INR
◆ Baseline
Brent Crude
FRED MCOILBRENTEU (EIA Europe Brent spot, monthly average of daily prices, $/bbl). Card = latest monthly average, not a current price. Chart quarter = mean of 3 complete months; incomplete quarters keep the baseline. EIA spot and Pink Sheet averages differ slightly.
Baseline: WB Pink Sheet (Apr-2026 edition) quarterly averages, verified through Q1 2026.
worldbank.org · Commodity Markets (Pink Sheet)
◆ Baseline
Source & refresh status
Provenance: LATEST = the provider was checked during this page load (or within the source's reuse window) and this is its newest published observation · CACHED = saved data shown because this load's check failed · SNAPSHOT = saved data, not re-checked (opened as a file or server unavailable) · STALE = a newer release is overdue for this series' publication schedule · BASELINE = embedded data (verified –) · MANUAL = maintained by hand · UNAVAILABLE = no usable data. Checking a source is not the same as receiving new data: the status table shows when each source was checked and whether a newer observation arrived. The header badge counts per-card states; one successful provider never turns the whole dashboard green.
Methodology: No annual-to-quarterly scaling or interpolation is performed anywhere (removed in v2) — quarterly values are either genuine API observations or curated baseline from primary publications. WB India conventions differ by series: CPI annual ≈ calendar-year average; GDP annual = India fiscal year (Apr–Mar, labelled by starting year). A ⚠ divergence flag appears if cross-check differs from baseline by >0.8 pp — if triggered, re-verify the basis before relying on either number. Historical values are the latest revised estimates from each provider, not first prints. localStorage is not used; saved data lives in data/macro_snapshot.js, written atomically by the local updater.
